## Notes for editing

- Handle visibility ranking (best first): 4 (BYD Seal) and 6 (Xpeng P7) show the
  flush handles most unmistakably (body-colored thin lip on the door). 1 (Model 3
  red, side) is also very clear. 3 (SU7 yellow) clear on the front door. 7 (C10
  grey) clear. 5 (Sealion 7) and 2 (Model Y) are 3/4-rear angles where the handle
  is visible but less prominent — fine if you want variety, weakest for a
  "look how flush this is" shot.
- The SU7 photo is the SU7 **Ultra** variant (showroom 2026). The recall article
  uses plain "SU7" per Reuters; the door handles are identical across variants,
  so the photo is fine — but don't caption it "SU7 Ultra" specifically if you
  want to stay consistent with the text.
- If you composite into one image, keep a small credit line on or below the
  image (CC BY-SA 4.0 requires attribution).
